# 🏘️ Lot Flip

A fast-paced web-based neighborhood real estate and property management strategy game.

## 🚀 Features
- **House Architectural Tiers:** Ranch, Colonial (+15% neighbor boost), and Mansion (+30% neighbor boost).
- **Community Upgrades:** Parks (+25% value / +20% rent) & Civic Centers (+15% global value / +$15/s revenue).
- **Auto-Rent & Listing Controls:** Properties begin earning passive rent upon construction; toggle listing status on demand.
- **Dynamic AI Market:** Pre-built neighbor properties go up for sale with real-time market price fluctuations.
- **Dual Gameplay Modes:** Choose between Timed Campaign Mode or Relaxed Goal Mode.
- **Clean Responsive UI:** Vector SVG rendering, dual opposing traffic lanes, and top status ribbon HUD.

## 🌐 Hosting Instructions

### Option 1: GitHub Pages (Recommended)
1. Push this directory to your GitHub repository (e.g., `github.com/tplunkett09/games` or a dedicated `lot-flip` repo).
2. Go to **Settings > Pages** in your repository.
3. Select `main` branch and `/ (root)` folder, then click **Save**.
4. Your game will be live at `https://tplunkett09.github.io/games/lot-flip/` (or your repo URL).

### Option 2: Netlify / Vercel
- Drag and drop this folder directly into Netlify Drop or connect your GitHub repository to Vercel for zero-config static hosting.

### Option 3: Local Static Web Server
```bash
npx serve .
```
Open `http://localhost:3000` in your web browser.
